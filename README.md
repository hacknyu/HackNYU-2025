## How to Contribute
1. Make a branch
    - Branch name should describe the task you're doing
2. Make a PR whenever you're done
4. Make sure your the checks at the end are successful
    - Specifically, if you make a PR, a link should be generated that would show a preview of your PR
    - Sometimes it takes a while for the PR preview to be updated with your changes so just wait a bit
3. Make sure you branch is up to date with main
    - `git merge main` or `git rebase main`
    - Use `merge` if you're not comfortable with `rebase`
